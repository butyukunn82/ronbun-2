# ST反射トレーナー 2026

2026年度の現行ITストラテジスト試験に向け、科目A-1・A-2・B-1・B-2の解答動作を段階的に身につける静的PWAです。

## 主な機能

- 科目A：用語直結、混同分離、4択、回答時間、忘却曲線型復習
- 科目B-1：設問要求、根拠抽出、言い換え、字数圧縮
- 科目B-2：出題意図、因果の型、経験カード、骨子、120分論述
- 用語タップ解説、誤答理由、学習履歴、バックアップ
- CBT形式、端末へのインストール、オフライン動作

## GitHub Pages

`dist` フォルダの中身をGitHubリポジトリの公開ルートへ配置してください。すべて相対パスなので、ユーザーサイトでもプロジェクトサイトでも動作します。

問題データは `dist/data/questions.js` に追加できます。現在の収録問題は学習設計と動作確認用のオリジナル問題です。公式過去問を追加する場合は、出典を明記してください。
